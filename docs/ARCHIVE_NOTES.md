# 整理说明

## 选择原则

以 `2-7组新生项目汇总/新生项目代码` 的 10 个 Python 文件为结题版本，全部纳入 `final_code/`。主目录的独立实验优先选择功能完整、能通过语法解析且有代表性的版本；共补充 10 个实验脚本。所有入选原文件均按字节复制，英文重命名不会改变内容。

重点保留三条技术路线：无人机视觉采集与标记对齐、图像处理与路径规划、地面机器人视觉识别。同时保留两种图像拼接思路供回顾；历史拼接并非结题总入口的依赖。

## 未纳入仓库的内容

| 内容 | 原因 |
| --- | --- |
| `.venv`、`.idea`、PyCharm、OpenCV、Anaconda 安装包、RoboMaster 桌面程序 | 开发环境和安装产物，应由依赖安装替代 |
| `yolo源码`、Ultralytics 压缩包、车牌识别项目压缩包 | 第三方完整项目，不冒充本项目代码 |
| `*.pt`、香蕉检测数据集 | 体积与来源管理需要，保留依赖名称，不重复打包 |
| `new矫正.py`、`new移动对齐尝试.py`、`路径规划1.py` | 当前副本存在语法/缩进错误，原文件留在原目录 |
| 空文件、简单 API 学习片段及大量近似迭代版本 | 对理解结题主流程帮助有限 |
| `小车行进4.0.py`、`小车行进5.0.py` 等早期行进草稿 | 结题版已经提供明确的角度/距离执行入口，早期文件仍保留在原目录 |
| 原始结题报告、过程报告及答辩 PPT | 报告含学号、联系方式等个人信息；公开技术说明从代码和报告中提炼 |
| 演示视频及其重复副本 | 首次代码归档优先保持轻量；可在确认展示范围后通过 Release 或外部链接补充 |

原目录没有被移动、删改。需要补回某个实验时，应先核对其依赖和与结题代码的关系。
