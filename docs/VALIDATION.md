## 未通过的样例复现

原始 `image_planner.py` 使用配套 `road mini.jpg` 可正常执行结束，但捕获画面中黄色路径像素数为 0，未生成可见规划路径。该原程序仅在 `found` 为真时绘制黄色路线，无路时仍显示原图并正常结束。验证时将显示函数替换为图像捕获，没有改动源文件；对保存图的视觉检查也未看到路线。

完整结题流程的结果如下。

在独立环境运行：

```powershell
python tools/run_planning.py --image assets/drone_capture.jpg --output runtime/archive_validation
```

原始 `Correct.main()` 输出空的标定端点列表 `[]`，之后发生 `IndexError: list index out of range`。该样例没有在原有参数下提取出后续透视校正需要的直线组合，流程未进入完整路径生成阶段。中间文件 `out_put/red_line.jpg` 保留在本地运行目录，运行目录已被 Git 忽略。

没有调整图像阈值来掩盖此结果，也没有对外声称原始总流程已经跑通。进一步修复需结合标定场地、采图颜色通道及原作者的运行参数。
